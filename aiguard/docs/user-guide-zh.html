AiGuard 使用手册（零基础版）

适用版本：v0.1.1（2026-09）· 平台：Windows 10/11 · macOS 10.15+ · Linux x64 本手册面向完全不懂技术的普通用户：每一步都可以照着做，不需要任何编程知识。

一、先弄明白：这是一个什么软件？

1.1 一句话介绍

AiGuard（AI 安全卫士）是装在你自己电脑上的「AI 对话安检门」：你发给 AI 的敏感信息（身份证号、手机号、银行卡号、密码、API 密钥等），它会先在本机换成"代号"再发出去；AI 写完回复后，它再把代号悄悄换回真实数据。AI 服务商从头到尾只见过"代号"，真实数据永远不出你的电脑。

1.2 它解决什么问题？（一个比喻）

把真实身份证号、银行卡号直接粘贴给 AI，就像把贵重物品裸露着交给快递公司——对方看得一清二楚，还可能留存底单。

AiGuard 的做法是：

步骤 发生什么 你能感觉到吗
① 你发出消息 软件在本机拦下请求，把身份证号等换成代号（如 [[PII:IDCARD:8f3a2b1c]]） 无感知，速度几乎不变
② AI 收到 只看到代号，不知道真实内容 无感知
③ AI 回复 回复里带着代号回到本机，软件把代号换回真实内容 你看到的就是真实数据
④ 全程 日志只记录"命中了什么类型"，不保存任何原文 审计页可查，无隐私泄露风险

1.3 适合谁用？

人群 典型场景
经常和 AI 聊天的人 让 AI 帮忙写投诉信、分析账单、处理合同，免不了粘贴个人信息
开发者 / 技术人员 在对话里粘贴报错日志、配置文件、代码，里面常含 API 密钥、内网地址
公司职员 用 AI 处理客户资料、报表，需要合规地避免数据外流
团队 / 企业 需要"数据不出本机"的可审计 AI 使用通道

1.4 它管不了什么（诚实的边界）

  • 只守护发往 AI 服务的流量（OpenAI、Anthropic、DeepSeek、Kimi、智谱、通义、文心、豆包、腾讯元宝等主流服务的 API 与网页域名）。你访问普通网站它一概不碰。
  • 使用了证书固定（certificate pinning）的应用会自动放行，守护不到。
  • 个别走 QUIC/HTTP3 直连的流量不经过系统代理，守护不到。
  • 它是本机安检门，不能清除你电脑上已有的病毒或键盘记录器。

1.5 核心能力一览

能力 说明
6 类内置检测规则 身份证号 / 手机号 / 银行卡号 / 邮箱 / API 密钥 / IP 地址
3 种处理动作 脱敏（换代号）/ 拦截（直接挡下不出网）/ 仅提醒
黑 / 白名单 指定域名或程序强制拦截、强制脱敏或完全放行

误报反馈 在请求 / 审计记录旁点「误报 / 确认」，审计页自动汇总近 30 天误报率，看清哪条规则最吵（v0.1.2 起）
凭据轮换提醒 保险柜登记的密钥被 AI 实际使用后自动提醒：已脱敏放行 = 黄色提示；明文外发 = 红色提醒立即轮换（v0.1.2 起）

二、安装前的准备

2.1 环境要求

项目 要求
Windows 10 / 11（64 位）；Win11 一般自带 WebView2，Win10 若提示缺组件按提示安装即可
macOS 10.15 及以上（Apple 芯片与 Intel 芯片同一个安装包）
Linux x64，安装 deb 包或 AppImage（需要 WebKitGTK 4.1 运行库）
硬盘空间 约 100 MB
管理员权限 常规使用不需要（证书装在"当前用户"信任库）；仅实验性 hosts 模式需要

2.2 下载安装包

  1. 打开浏览器，访问项目发布页：https://github.com/Technicalflight/AiGuard/releases
  2. 在最新版本（如 v0.1.1）的 Assets 列表里，按你的系统下载对应文件：
系统 选这个文件
Windows *-setup.exe（推荐）或 *.msi
macOS *.dmg
Linux *.deb 或 *.AppImage
  1. Windows 双击 *-setup.exe，按安装向导点「下一步」即可完成。

系统提示 原因 怎么办

macOS「无法验证开发者」 同上 在安装包图标上右键 → 打开，再点「打开」
杀毒软件提示 本软件包含代理与证书功能，属正常特征 选择「允许」并加入信任

三、第一次启动：三步向导

安装完成后启动软件，会自动弹出首次运行向导，一共三步。每一步都可以跳过（向导只是检查清单，不是强制门槛），以后可随时在「设置 → 首次运行向导 → 重新运行」再来一遍。

第 1 步：安装根证书

  1. 点「安装根证书」按钮。
  2. 系统可能弹出一次确认框，点「是 / 确定」。
  3. 界面显示证书状态变为「已安装」即成功。

为什么要装证书？ 就像安检员需要一张"工作证"才能拆开信封检查，AiGuard 需要一张自己签发的证书才能看懂发往 AI 的加密流量、完成脱敏。这张证书：

  • 只装到你当前用户的信任库，不需要管理员权限；
  • 只用于本机发往 AI 服务的流量检查，绝不能提供给任何第三方（私钥受系统加密保护）；
  • 随时可以在设置里撤销。

📷 建议截图：向导第 1 步「安装根证书」

第 2 步：开启守护（设置系统代理）

  1. 点「开启守护」按钮。
  2. 软件会把系统代理指向本机的安检管道（模式为"系统代理 + PAC"——普通网站全部直连不受影响，只有 AI 域名进管道）。
  3. 状态变为「守护中」即成功。

📷 建议截图：向导第 2 步「开启守护」

第 3 步：确认检测规则

  1. 页面会列出默认开启的检测规则（身份证 / 手机号 / 银行卡 / 邮箱 / API 密钥等）。
  2. 直接点「开始使用」接受默认即可；想调整可以之后在「规则中心」慢慢改。

四、日常使用全流程（核心操作）

按真实使用顺序，一共 6 步：

步骤 1：开启守护

四种方式任选其一：

方式 操作
标题栏 点窗口右上角的「代理开关」
首页 点绿色大按钮「立即开启守护」
托盘 右键任务栏右下角盾牌图标 → 「开启守护」
快捷键 任意窗口下按 Ctrl + Alt + G

开启后：侧栏底部圆点变绿并呼吸闪烁，托盘菜单显示「状态：守护中」。

步骤 2：像平常一样使用 AI

  • 浏览器打开 AI 网页、桌面客户端、命令行工具，都不需要额外配置，直接正常对话即可。
  • 粘贴包含手机号、身份证号的内容后发出——软件会在后台自动完成脱敏。

步骤 3：在首页观察守护动态

首页会实时刷新：

区域 含义
四格数字 今日请求 / 已脱敏 / 已拦截 / 活跃会话数量
脱敏流水（弹幕） 滚动显示最近命中的类型与动作，如「手机号 138****5678 · 已脱敏」
当前活跃会话表 哪个域名、哪个程序正在被守护；点「切断」可销毁该会话的本机映射
已守护 N 天 累计使用天数

步骤 4：查看每一次请求的明细

  1. 点左侧导航「请求」进入实时请求页。
  2. 顶部筛选按钮：「全部 / 已脱敏 / 已拦截」。
  3. 表格列出时间、域名、命中类型、动作、哈希（哈希是"指纹"，不含原文）；点任意一行可看详情弹窗。

步骤 5：查看审计日志

  1. 点左侧导航「审计」。
  2. 页面顶部有隐私说明：日志仅记录命中类型与哈希，不保存任何原文。
  3. 支持按日期筛选，逐页翻看历史记录。

步骤 6：暂停守护或退出

想做什么 怎么做
临时暂停 标题栏代理开关关掉 / 托盘「暂停守护」/ Ctrl+Alt+G。流量恢复直连
关闭窗口 默认会弹询问：「退出程序」或「最小化到托盘」（可在设置改为不再询问）
彻底退出 托盘右键 →「退出」。退出前软件会自动还原系统代理，网络不会留后遗症
紧急情况 点首页红色「一键应急切断」或按 Ctrl+Alt+X：清空本机映射 + 关闭守护 + 撤销证书，一步到位

5.2 实时请求页

控件 作用
筛选按钮「全部 / 已脱敏 / 已拦截」 只看某一类请求

5.3 规则中心（内容最多的一页）

页面顶部有一条优先级提示：黑名单 ＞ 白名单 ＞ 检测规则（黑名单优先级最高）。

卡片 / 控件 作用
「检测规则」卡片 6 条内置规则，每条可：开关启用、改动作（脱敏 / 拦截 / 仅提醒）、编辑正则、设确认次数（达到次数才拦截，防误报）、一键恢复默认
「新增自定义规则」 自定义名称、占位标签、正则表达式、动作
「内置规则预设」 三档一键切换：保守 / 均衡 / 激进（见 6.1 对照表）
「正则测试器」 输入一段文本和正则，实时测试命中效果（与线上引擎完全一致）
「执行顺序」 可视化展示 黑名单 → 检测规则+语义 → 白名单 → 还原 的流程；点节点直接打开名单管理
「黑名单」卡片 添加域名或程序 + 命中动作（命中即拦截 / 强制脱敏）；优先级最高，白名单也覆盖不了它
「白名单」卡片 添加域名或程序；默认完全不拦截；「仍执行脱敏」开关决定是否还做脱敏。程序支持「浏览文件… / 浏览文件夹…」选取
「导入 / 导出」卡片 把规则 + 黑白名单打包成 JSON 文件备份，或导入恢复
「语义检测」卡片 四个开关：高熵字符串 / 中文姓名 / 机构名 / 地址（命中恒为脱敏）；「产品代号白名单」可避免自家产品名被误伤
「保险柜」卡片 ① 值条目：登记密钥等具体值（出站即脱敏/拦截）② 路径条目：登记 .env、私钥等文件（支持 *.pem 通配），AI 试图读取就告警

控件 作用

5.6 设置页（从上到下）

分区 作用与关键项
「拦截模式」 三张卡：系统代理 + PAC（推荐，默认） / hosts 模式（实验性）/ TUN 模式（规划中）
「CA 根证书」 显示证书状态与路径；按钮：安装根证书 / 重新检测 / 配置 Node 客户端信任（用 Node 写的 CLI 工具需要它，详见 FAQ）；下方有风险提示
「本机安全加固」 本地代理访问控制（仅接受本机连接）、要求令牌（给 CLI/SDK 用，代理地址 http://令牌@127.0.0.1:8888）、端口占用检测、内存安全擦除、防调试、证书私钥保护、数据目录隔离、启动自检结果
「桌面通知」 总开关 + 触发门槛（默认"高危及以上"，门槛越严越安静）+「发送测试通知」
「日志清理」 直通 / 已脱敏 / 已拦截 三类记录分别设保留天数（0 = 永久保存）；「立即清理」「清空全部请求日志」
「数据安全」 「退出时清空映射表」开关
「接管范围」 自定义接管域名：使用小众 AI 服务时把它的域名加进来（每行一个），三个接管链路（PAC / hosts / 代理）同步生效
「关闭窗口」 点窗口 ✕ 时：每次询问（默认） / 直接退出程序 / 直接最小化到托盘
「界面语言」 简体中文 / English（窗口、托盘、通知一起切换）
「全局快捷键」 开关守护（默认 Ctrl+Alt+G）、一键应急切断（默认 Ctrl+Alt+X）；只能从预设键位里选，可整体关闭
「自动检查更新」 默认关闭（关闭时零联网）；开启后仅向 GitHub Releases 发一个查询请求
「首次运行向导」 「重新运行」按钮

六、进阶功能

6.1 三档防护预设怎么选？

档位 开启的规则 命中后动作 适合谁
保守 身份证 / 银行卡 / API 密钥 脱敏 怕误报打扰、只关心核心证件与密钥的人
均衡（默认） 身份证 / 手机号 / 银行卡 / 邮箱 / API 密钥（IP 关闭） 脱敏 大多数人
激进 全部 6 类 身份证 / 银行卡 / API 密钥改为拦截 处理高敏感数据、宁可错杀不可放过

切换位置：规则中心 →「内置规则预设」卡片。

6.2 使用小众 AI 服务时（自定义接管域名）

内置域名清单之外的服务默认不走守护。解决办法：

  1. 设置 → 「接管范围」。
  2. 在输入框里填该服务的域名，每行一个（填对话网页和 API 域名都可以）。
  3. 保存后 PAC / hosts / 代理三条链路同步更新，该域名立即进入守护。

6.3 保险柜：保护你的密钥和文件

  • 值条目：登记具体密钥（如 OPENAI_API_KEY = sk-xxx）。此后只要出站流量里出现这个值，自动脱敏或拦截；若 AI 的回复里试图让你执行读取这类密钥的命令，会触发「保险柜访问」告警。
  • 路径条目：登记文件路径或通配模式（如 .env、*.pem）。有程序试图读取这些受保护对象时立即告警。
  • 用完即改提醒（v0.1.2 起）：登记的密钥被 AI 实际用到时（不是提到名字，是真的发送了这个值），首页横幅自动提醒——
    • 绿色：密钥已被换成代号再发出去，AI 拿到的是假值。如果模型因此"调用失败"，属正常现象，无需处理；
    • 红色：你把该域名加入了白名单、密钥以明文发出去了——建议立即到对应平台重置（轮换）这把密钥，然后在保险柜里更新条目。窗口不在前台时这条提醒会走系统通知。
    • 同一条目 10 分钟内只提醒一次，不刷屏；提醒里只有条目名字和次数，永远不含密钥值本身。
  • 条目即存即生效，最多 200 条，值至少 8 个字符。

6.4 命令行 / Node.js 用户须知

  • 一般 CLI 工具：设置环境变量 http_proxy=http://127.0.0.1:8888 与 https_proxy=http://127.0.0.1:8888 即可让流量进守护。
  • Node.js 系工具（npm、各类 AI CLI）不认系统证书：设置页点「配置 Node 客户端信任」一键写入 NODE_EXTRA_CA_CERTS（仅 Windows 支持一键，其他系统按界面提示手动设置），然后完全重启对应客户端。

6.5 应急切断：什么时候用、会发生什么

怀疑数据已经泄露、或想把所有痕迹立刻清掉时使用。动作：清空本机占位符映射 → 关闭守护 → 撤销根证书。注意：切断后，之前会话的 AI 回复里若还残留占位符，将无法再还原。

八、常见问题（FAQ）

8.1 网络与访问类

问题 原因 解决办法
开启守护后，某个 AI 网页打不开 / 一直转圈 该域名不在守护清单内但被代理环境干扰，或证书未装好 ① 确认已安装根证书（设置 → CA 根证书 → 重新检测）② 临时暂停守护对比 ③ 若用的是小众 AI 服务，把它加进「接管范围」
AI 网页报"证书错误 / 不安全" 根证书未安装成功，或装错了用户 设置 → CA 根证书 → 「安装根证书」重装；确认当前登录的就是安装时的用户
桌面 AI 客户端不走守护 客户端未跟随系统代理 在客户端的网络设置里手动填代理 127.0.0.1:8888；Node 系客户端先点「配置 Node 客户端信任」再完全重启
某些浏览器插件 / 其他代理软件冲突 多个代理抢系统代理设置 二选一：关闭其他代理软件，或在其内部把上游代理指向 127.0.0.1:8888
退出软件后网络异常（极少见） 进程被强制结束，代理设置没来得及还原 系统设置里手动关闭代理：Windows「设置 → 网络和 Internet → 代理」关闭"使用设置脚本"；以后尽量用托盘「退出」

8.2 守护效果类

问题 原因 解决办法
AI 回复里出现 [[PII:...]] 没被还原 该会话映射已被切断 / 超时（默认 30 分钟无活动）/ 跨了会话 把这个问题重新问一遍（新会话会建立新映射）；应急切断或「清空会话映射」后旧占位符无法还原，属正常
提示"已拦截"，AI 根本没收到消息 命中了动作=拦截的规则（激进预设下身份证 / 银行卡 / 密钥必拦截），或命中了黑名单 若确认要发送：规则中心把该规则动作改为「脱敏」，或把该域名 / 程序加入白名单
明明粘贴了敏感信息却没有任何记录 该域名不在守护范围（先确认是主流 AI 服务），或对应规则被关了 检查规则中心规则开关；小众服务加「接管范围」
误报太多（正常内容被脱敏） 规则太严格 ① 预设切到「保守 / 均衡」② 用「正则测试器」调整规则 ③ 把可信域名 / 程序加入白名单 ④ 语义检测里关闭部分开关或把产品名加进白名单 ⑤ 在「请求 / 审计」页点「误报」反馈，「反馈统计」会直接指出误报最多的规则（v0.1.2 起）
漏报（没识别出某种敏感信息） 内置 6 类规则覆盖不了所有格式 规则中心 → 新增自定义规则（写一条正则）；或把值登记进保险柜（精确匹配，绝不漏）

8.3 通知与账号类

问题 原因 解决办法
明明拦截了却没弹通知 主窗口在前台时不弹（有意设计）；或事件没到通知门槛 设置 → 桌面通知 → 降低「触发门槛」；先点「发送测试通知」验证系统权限

界面变成英文了 语言被切换 设置 → 界面语言 → 简体中文

十、隐私与安全设计（为什么可以放心用）

  1. 原文不落盘：日志与审计只存"命中类型 + 哈希指纹"，任何环节不保存敏感原文。你点的「误报 / 确认」也只存一个标签词和时间，不带任何内容（v0.1.2 起）。
  2. 原文不出网：脱敏、还原、审计全部在本机完成；软件不把你的数据发给任何第三方。
  3. 内存即用即毁：原文↔占位符映射只在本机内存，会话结束 / 超时自动用零覆写销毁。
  4. 私钥加密保存：证书私钥在 Windows 上经系统级加密（DPAPI），只有你的登录用户能解密。
  5. 自我加固：端口仅监听本机回环、可选访问令牌、启动自检、防调试检测。
  6. 默认不联网：自动更新默认关闭，关闭期间零网络请求。
